# USCPI-reconstruction & Forecast
Reconstructing U.S. CPI-U from detailed component indexes and historical expenditure weights using Python.
Also trying to build a forecast model for US CPI. I've tried quite a few models and kept 2 I was fairly happy about (SARIMAX and MARS). I'd be keen to get feedbacks on how to improve it, I seem to have hit a wall at the moment. I've tried a lot of different exogenous variables and it seems so far that Oil and Housing are doing a good-ish job. Obviously, this is a work in progress and it needs improvement. Keen to get feedbacks.
